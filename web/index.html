Remove old token approvals on Solana.

Apps you used once can still move your tokens. Velon shows which ones can, removes the access you choose, and checks the chain afterwards to confirm it is gone.

Approvals stay after you leave the app.

Swaps, aggregators, payment and subscription apps often ask for permission to move a token from your wallet later. Closing the tab doesn't end it. That key can keep moving the token without asking again until you remove its access.

If one of those apps is hacked, every wallet that approved it needs to remove that access quickly, and know that it worked.

Checked before you sign, and again after.

Tested before you sign

Velon runs the exact removal itself, on the finalized state it read, with that network's active features and the verified SPL Token program. The RPC provider's simulation must end in the same account state.

Shows who holds each approval

Read from the chain: a wallet, a program or a program's account. Velon names an app only when it is a known program.

Stops if anything disagrees

If any check fails, Velon offers nothing to sign. Some of the runtime's refusals:

  • feature unknown to the pinned runtime
  • simulation precedes observation
  • simulation/context slot mismatch
  • feature evidence outside observed bank

Read again once final

"Removed and verified" appears only after Velon reads the final chain state and the approval is gone.

A receipt you can check later

Every verified removal keeps its evidence. Replay it later, without the chain, and it still checks out.

How a removal works

  1. 01

    Read

    Velon reads your token accounts from the chain's final state and lists each approval and how much it allows.

  2. 02

    Test

    Velon runs the removal itself on that same state. The RPC provider's simulation must match it.

  3. 03

    Sign

    Your wallet signs exactly the transaction you reviewed, and nothing else.

  4. 04

    Verify

    Once the chain is final, Velon reads the account again, confirms the approval is gone and gives you a receipt.

Who it is for

Wallets

Show who can take each token next to its balance. The SDK reads token accounts into exact permissions and builds removals your users review before they sign.

Treasuries

List the approvals on a team's token accounts. The SDK also models Squads V4 spending limits.

After an exploit

When an app is hacked, each affected wallet sees the exact approval, signs one reviewed removal and gets a receipt.

Open source

The runtime, the SDK and the console are in one public repository. Run it with recorded evidence, point it at mainnet or devnet, or start a local validator with the real SPL Token program.

Run it locally 
$ git clone https://github.com/dakewamama/velon.git
$ cd velon/app
$ npm ci --ignore-scripts
$ bun run demo

Opens on http://127.0.0.1:3000 with recorded evidence. No RPC key needed.

Check your wallet

Paste any address or connect a wallet. Velon lists the token approvals on it and removes the ones you choose, when it can verify them. Nothing to install.
